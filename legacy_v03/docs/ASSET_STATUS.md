# Asset status — read before development

This pack is a **starter handoff**, NOT all assets a finished open-world game will ever need.

- New GLB files: static low-poly blockouts, **not photorealistic**, not rigged, not skinned, not collision-ready.
- Six character viewpoint PNGs: reference crops, **not independent orthographic renders**.
- Animation contract: requested clip names only, **not finished clips**.
- Vehicle mode variants: copied meshes, **not working transformations**.
- Textures: simple swatches, **not authored PBR texture sets**.
- Sound effects, music, voices: **not included**.
- No copyrighted Batman/Arkham game assets are included. Maintain original Crimson Knight branding.
- No functional combat, NPC AI, physics or open-world systems are included in this pack.
