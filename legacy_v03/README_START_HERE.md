# CRIMSON KNIGHT — VISUAL-FIRST HANDOFF v0.3

1. Open `reference/production_board/full_animation_reference_board.png` and its seven cropped sections.
2. Read `docs/IMAGE_TO_3D_PIPELINE.md`.
3. Upload this ZIP to Claude and give it `docs/CLAUDE_VISUAL_FIRST_PROMPT.md`.
4. Existing `models/*.glb` are static blockouts, not finished rigged characters.
5. Images are concept art, not calibrated animation frames or true multi-view scans.

This package contains a reference atlas and cropped regions, prior concept art, existing starter GLBs, textures, scene pieces and animation specifications. It does **not** contain hundreds of independently rendered animation frames or production-ready rigged assets.
