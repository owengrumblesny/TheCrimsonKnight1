The icons are INDIVIDUAL transparent files, not one atlas.
Every unique symbol has an SVG and PNG without background (/glyph/) and in a circular crimson frame (/circle/).
PNG: 256 x 256 pixels; SVG: scalable editable icon geometry. Transparent background.
All art in this pack is new original vector-style iconography, not game meshes.

config/icon_manifest.json lists every icon's actual path.
config/hotbar_layout.json gives default hotbar key mappings and design specs.
config/menu_spec.json describes the intended menus.
previews/ are optional overview images, not the assets to use in the game.

Unzip into the project or copy assets/ to public/ui/assets and configs to public/ui/config. Follow the guide for deployment path handling.
